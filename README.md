# Yardline — Factory Operations Pilot

End-to-end truck turnaround and dock coordination, built for the Framsikt Engineering Fundamentals exercise.

This project is a proposed, evidence-driven pilot using entirely synthetic factory data. It does not claim the original factory's delays are caused by dock coordination.

Applications: `ui/` (React + TypeScript) and `backend/` (FastAPI + PostgreSQL). See `docs/ENGINEERING_DECISIONS.md` for the interview narrative.
